DipFlow — a mean-reversion dip bot for pump.fun bonding curves. It reads replayed pump.fun market events and trades paper SOL: it buys curves that pulled back 8%-45% from their recent high while buyers step back in, adds in small tranches, and exits on take-profit, recovery of half the dip, stop-loss, or time. Built by an AI agent for make.fun's “Pump.fun Bot Sprint: Make Bot And Win” bounty, $2 in USDC.

## Run it

```sh
PYTHONHASHSEED=0 python3 -P -s main.py
```

The bot speaks agent-fun/replay/v2 on stdin/stdout (JSON lines in, one reply per batch out).
